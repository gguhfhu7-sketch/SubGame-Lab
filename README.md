## 🇮🇷 راهنمای فارسی

### 🌐 نسخه آنلاین — بدون نصب

ساده‌ترین راه: همین لینک را در مرورگر (کروم یا اج) باز کنید:

**👉 https://sub-dfh9.onrender.com/**

- چیزی نصب نمی‌خواهد؛ فقط یک **کلید API جمینای** (یا سرویس جایگزین) لازم دارد — آموزشش پایین‌تر آمده.
- سرور رایگان است؛ اگر مدتی کسی وارد نشده باشد «می‌خوابد» و **باز شدن اول ممکن است تا یک دقیقه طول بکشد** — صبر کنید و یک‌بار صفحه را رفرش کنید.
- همه‌ی کارها و کلید شما فقط در **مرورگر خودتان** ذخیره می‌شود؛ چیزی روی سرور ذخیره نمی‌شود. قبل از بستن مرورگر، خروجی کارتان را دانلود کنید.

### ✨ این برنامه چه کار می‌کند؟

- **حالت سینما:** زیرنویس‌های `SRT` ،`VTT` ،`ASS` و… را ترجمه می‌کند؛ می‌توانید متن، ترجمه و زمان‌بندی را ویرایش کنید، زیرنویس دوزبانه بسازید و روی فیلم پیش‌نمایش بگیرید.
- **حالت بازی:** فایل‌های متنی بازی مثل `CSV` ،`JSON` ،`XLSX` ،`TXT` را ترجمه می‌کند و متغیرهای داخل متن بازی را کنترل می‌کند.
- **امکانات مشترک:** انتخاب زبان مقصد و لحن ترجمه، چند کلید هم‌زمان برای جمینای، استفاده از سرویس‌های جایگزین (Custom Provider)، جست‌وجو و جایگزینی، ذخیره خودکار در مرورگر.

### 💻 اجرا روی کامپیوتر خودتان (گام‌به‌گام)

اگر نسخه آنلاین برایتان کافی است، این بخش را لازم نیست بخوانید. برای اجرای برنامه روی سیستم خودتان (حتی بدون اینترنتِ پایدار بعد از نصب) این ۵ قدم را به‌ترتیب انجام دهید.

#### قدم ۱ — نصب Node.js

1. به سایت **https://nodejs.org** بروید.
2. نسخه‌ی **LTS** را دانلود کنید (حداقل نسخه ۲۲) و مثل یک برنامه معمولی نصبش کنید — فقط Next بزنید تا آخر.
3. یک‌بار **همه پنجره‌های ترمینال را ببندید و دوباره باز کنید** تا نصب شناسایی شود.
4. برای آزمایش، ترمینال را باز کنید و بنویسید:

```
node -v
```

اگر یک عدد مثل `v22.14.0` چاپ شد، نصب موفق بوده. اگر پیام «شناخته نشده» دادید، قدم ۱ را از اول تکرار کنید.

#### قدم ۲ — باز کردن پوشه پروژه در ترمینال

پوشه‌ی پروژه را از فایل زیپ بیرون بیاورید (مثلاً در دسکتاپ). حالا باید داخل همان پوشه یک ترمینال باز کنید:

- **ویندوز:** پوشه را در File Explorer باز کنید، در **نوار آدرسِ بالای پنجره** کلمه‌ی `cmd` را بنویسید و Enter بزنید. یک پنجره سیاه در همان پوشه باز می‌شود.
- **مک:** روی پوشه راست‌کلیک کنید و از منو «New Terminal at Folder» را انتخاب کنید، یا ترمینال را باز کنید و با دستور `cd` وارد پوشه شوید.

#### قدم ۳ — نصب (فقط بار اول)

در همان پنجره ترمینال این را بنویسید و Enter بزنید:

```
npm install
```

- این مرحله همه‌ی اجزای برنامه را دانلود می‌کند و **بار اول چند دقیقه طول می‌کشد** — صبر کنید تا تمام شود.
- دفعات بعدی لازم نیست تکرار شود.

#### قدم ۴ — اجرای برنامه

```
npm run dev
```

وقتی این پیام را دیدید، برنامه آماده است:

```
🚀 Server listening on http://0.0.0.0:3000
```

> ⚠️ این پنجره ترمینال را **باز نگه دارید**؛ بستنِ آن یعنی خاموش شدن برنامه.

#### قدم ۵ — باز کردن برنامه در مرورگر

در مرورگر (کروم یا اج) این آدرس را باز کنید:

```
http://localhost:3000
```

- **خاموش کردن برنامه:** در پنجره ترمینال کلیدهای `Ctrl + C` را بزنید.
- **دفعات بعد:** فقط قدم ۲ و ۴ و ۵ — یعنی ترمینال را در پوشه باز کنید، `npm run dev` بزنید و آدرس را در مرورگر باز کنید. `npm install` دیگر لازم نیست.

### 🔑 کلید API جمینای از کجا بگیرم؟

برنامه برای ترجمه به یک کلید API از گوگل (Gemini) نیاز دارد. گرفتنش رایگان و دو دقیقه طول می‌کشد:

1. به سایت **https://aistudio.google.com** بروید (در صورت نیاز با ابزار تغییر IP — توضیح در بخش نکته‌ها).
2. با اکانت گوگل وارد شوید، روی **Get API key** و بعد **Create API key** بزنید و کلید را کپی کنید.
3. در برنامه، روی منوی **«کلید API»** در بالای صفحه بزنید، کلید را بچسبانید و ذخیره کنید.

- کلید شما **فقط در مرورگر خودتان** ذخیره می‌شود و روی هیچ سروری ذخیره نمی‌شود.
- اگر کلید خطا داد: چک کنید موقع کپی ناقص کپی نشده باشد؛ اگر پیام محدودیت/سهمیه (مثل 429) دیدید، چند دقیقه بعد دوباره امتحان کنید یا کلید دیگری اضافه کنید. برنامه از چند کلید به‌صورت چرخشی پشتیبانی می‌کند.

### ⚙️ استفاده از سرویس جایگزین (Custom Provider)

اگر به جمینای دسترسی ندارید یا ترجیح می‌دهید از سرویس دیگری استفاده کنید:

1. در منوی **کلید API**، گزینه‌ی **Custom Provider** را انتخاب کنید.
2. **Base URL**، **کلید API** و **Model ID** سرویس‌تان را وارد کنید (این‌ها را خود همان سرویس به شما می‌دهد).
3. روی **Test Connection** بزنید تا مطمئن شوید وصل شده، بعد ترجمه را شروع کنید.

سرویس‌هایی که API سازگار با `chat/completions` بدهند (مثل OpenRouter، Groq، DeepSeek و…) قابل استفاده‌اند. نکته‌ها: آدرس‌های لوکال (مثل Ollama روی همین سیستم) در این نسخه مسدود است؛ حالت استریم زنده مخصوص جمینای است و با سرویس جایگزین به‌صورت عادی (دسته‌ای) ترجمه می‌شود.

### 💡 نکته مهم: دسترسی و VPN

این نکته‌ها مخصوص **اجرای لوکال** است و ممکن است بسته به کشور و شبکه‌ی شما مهم شود:

- درخواست‌های ترجمه از **کامپیوتر خود شما** به سرور سرویس‌دهنده (گوگل یا سرویس جایگزین) فرستاده می‌شود؛ پس سیستم شما باید به آن سرویس دسترسی داشته باشد.
- در برخی کشورها (مثلاً ایران) سرویس‌های گوگل معمولاً بدون ابزار تغییر IP (VPN/تحریم‌شکن) باز نمی‌شوند. اگر برنامه بالا آمد ولی موقع ترجمه خطای شبکه یا اتصال گرفت، اول این را بررسی کنید که ابزار شما روشن باشد.
- در دموی آنلاین هم همین‌طور است: دسترسی در همه‌ی کشورها و شبکه‌ها تضمین نمی‌شود و به مسیر شبکه‌ی شما بستگی دارد.
- اگر نمی‌خواهید از ابزار تغییر IP استفاده کنید، همان **Custom Provider** را با سرویسی که در شبکه‌ی شما در دسترس است تنظیم کنید.
- استفاده از هر سرویس تابع قوانین و شرایط خودش است؛ چند کلید داشتن، سهمیه‌ی سرویس را بیشتر نمی‌کند.

### 🛠 مشکلات رایج و راه‌حل ساده

| مشکل | راه‌حل |
|---|---|
| پیام «`npm` شناخته نشده» | Node.js درست نصب نشده یا ترمینال قدیمی است. همه ترمینال‌ها را ببندید و یکی تازه باز کنید؛ اگر نشد، قدم ۱ را دوباره انجام دهید. |
| صفحه در مرورگر باز نمی‌شود | صبر کنید پیام `Server listening` در ترمینال بیاید. آدرس را دقیقاً `http://localhost:3000` بنویسید (اولش `https` نگذارید). |
| خطای `EADDRINUSE` یا پورت اشغال | برنامه‌ی دیگری روی پورت ۳۰۰۰ است. آن را ببندید، یا برنامه را روی پورت دیگر اجرا کنید — ویندوز (PowerShell): `$env:PORT=3001; npm run dev` — مک/لینوکس: `PORT=3001 npm run dev` — و در مرورگر همان پورت جدید را باز کنید. |
| خطای کلید API یا 429 | کلید را دوباره کپی کنید؛ اگر سهمیه پر شده چند دقیقه صبر کنید یا کلید دیگری اضافه کنید. |
| `npm install` خطا داد یا نیمه‌کاره ماند | اینترنت را چک کنید، پوشه‌ی `node_modules` را پاک کنید و دوباره `npm install` بزنید. |
| ترجمه شروع نمی‌شود / وسط کار خطا می‌دهد | دسترسی به سرویس (بخش نکته‌های VPN)، اعتبار کلید، و فرمت فایل را چک کنید. برای فایل‌های خیلی بزرگ، تعداد خطوط هر دسته را در تنظیمات کمتر کنید. |
| بعد از بستن مرورگر کارهایم نیست | نشست‌ها در مرورگر ذخیره می‌شوند ولی بهترین کار این است که قبل از خروج، خروجی (Export) بگیرید. پاک‌کردن داده‌های سایت، ذخیره‌ها و کلیدها را حذف می‌کند. |

### 🔒 حریم خصوصی در سه خط

کلیدها و نشست‌های کاری فقط در مرورگر شما (localStorage و IndexedDB) ذخیره می‌شوند. روی دستگاه مشترک کلید ذخیره نکنید و کارهای مهم را مرتب Export بگیرید. حفاظت‌های داخلی برنامه جای یک بررسی امنیتی کامل را نمی‌گیرند.

### ⚙️ برای کاربران حرفه‌ای (اختیاری)

- متغیرهای اختیاری سرور (مثل کلید سمت سرور یا محدودیت نرخ) در فایل `.env.example` توضیح داده شده‌اند — برای استفاده‌ی عادی لازم نیستند.
- نسخه‌ی بهینه (production): دستورهای `npm run build` و بعد `npm start` و باز کردن همان `http://localhost:3000`.

## 🇬🇧 English — Quick start

**AI workspace for cinema subtitles and video-game localization.**

- **Live demo (no install):** https://sub-dfh9.onrender.com/
- Free-tier servers sleep after ~15 min idle; the first load may take up to a minute — just wait and refresh.

**Run locally (5 steps):**

1. Install the current **Node.js 22 LTS** from https://nodejs.org, then reopen your terminal. Verify with `node -v`.
2. Extract the project folder and open a terminal **inside it** (Windows: type `cmd` in the folder's address bar).
3. `npm install` — first time only, takes a few minutes.
4. `npm run dev` — wait for `🚀 Server listening on http://0.0.0.0:3000`. Keep this terminal window open.
5. Open `http://localhost:3000` in Chrome/Edge. Stop with `Ctrl + C` in the terminal.

**API key:** get a free Gemini key at https://aistudio.google.com (Get API key → Create API key), then paste it in the app's **API Key** menu. Keys are stored only in your browser.

**Network/VPN note:** translation requests go out from **your machine** to the provider (Google or a custom provider). In some regions (e.g., Iran) Google services may need a VPN/proxy; if the app loads but translation fails with a network error, check that first. Alternatively configure a **Custom Provider** (OpenRouter, Groq, DeepSeek, …) that is reachable from your network.

## 🇸🇦 العربية — بداية سريعة

**استوديو ذكاء اصطناعي لترجمة ترجمات الأفلام ونصوص الألعاب.**

- **النسخة الجاهزة (دون تثبيت):** https://sub-dfh9.onrender.com/
- الخطة المجانية تدخل في وضع السكون بعد نحو 15 دقيقة؛ قد يستغرق الفتح الأول حتى دقيقة — انتظر ثم حدّث الصفحة.

**التشغيل المحلي (5 خطوات):**

1. ثبّت **Node.js 22 LTS** من https://nodejs.org ثم أعد فتح الطرفية وتحقق بـ `node -v`.
2. فك ضغط مجلد المشروع وافتح الطرفية **داخله** (ويندوز: اكتب `cmd` في شريط عنوان المجلد).
3. `npm install` — للمرة الأولى فقط ويستغرق بضع دقائق.
4. `npm run dev` — انتظر رسالة `🚀 Server listening on http://0.0.0.0:3000` وأبقِ نافذة الطرفية مفتوحة.
5. افتح `http://localhost:3000` في المتصفح. للإيقاف اضغط `Ctrl + C` في الطرفية.

**مفتاح API:** احصل على مفتاح Gemini مجاني من https://aistudio.google.com ثم ألصقه في قائمة **مفتاح API** داخل التطبيق. تُحفظ المفاتيح في متصفحك فقط.

**ملاحظة الشبكة/VPN:** تخرج طلبات الترجمة من **جهازك** إلى المزوّد (Google أو مزوّد بديل). في بعض المناطق قد تحتاج إلى VPN؛ وإن لم ترغب بذلك فاضبط **Custom Provider** مع خدمة متاحة في شبكتك (OpenRouter، Groq، DeepSeek وغيرها).
